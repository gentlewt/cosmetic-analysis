# 내 화장품 조합, 나에게 잘 맞을까?

흰색·라벤더 테마의 반응형 스킨케어 웹서비스 초기 프로젝트입니다. Vite + JavaScript + CSS로 구성하며 Node.js 22.12 이상을 사용합니다.

## 개발

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

홈, 루틴 분석, 제품 검색·비교, 성분 사전, 피부 고민별 추천, 피부 변화 기록, 마이페이지를 해시 라우팅으로 제공합니다. 모든 제품은 가상의 예시이며 분석은 선택한 제품의 성분 중복만 표시합니다. 피부 기록은 해당 브라우저의 localStorage에 저장되며 삭제할 수 있습니다. 루틴과 비교 선택은 새로고침 시 초기화됩니다. 로그인 및 서버 동기화는 미구현입니다.

## Supabase (다음 단계)

현재 Supabase SDK, 네트워크 연결, 마이그레이션 및 초기화 명령은 없습니다. 기존 데이터베이스를 변경하지 않습니다. 필요할 때 `.env.example`을 `.env.local`로 복사하고 URL 및 브라우저용 publishable key를 설정하세요. VITE_ 변수는 빌드 결과에 공개되므로 service_role 키, 비밀번호, 서버 전용 API 키를 절대 입력하지 마세요. `.env` 및 `.env.*`는 예시 파일을 제외하고 Git에서 무시됩니다.

## Cloudflare Pages 설정 안내 (배포하지 않음)

- 프레임워크: Vite
- 빌드 명령: `npm run build`
- 출력 디렉터리: `dist`
- 프로젝트 루트: 저장소 루트
- Node.js: 22.12 이상

정적 파일만 출력하며 해시 라우팅이므로 별도 서버나 경로 리라이트가 필요하지 않습니다. 이 작업은 배포나 Pages 프로젝트 생성을 수행하지 않습니다.

## 테스트

`npm test`는 제품 검색과 성분 중복 집계를 검증합니다. 브라우저에서 각 메뉴, 검색, 비교 선택 제한, 루틴 선택, 기록 저장·삭제 및 모바일 화면을 추가로 확인하세요. 외부 폰트가 차단되면 시스템 sans-serif로 표시됩니다.
